# Project Instructions

## Communication
- Communicate with the developer in English.
- Write code, identifiers, comments, and documentation in English.
- Keep user-facing UI text and mock data in Spanish.

## Development
- Inspect existing patterns before introducing new abstractions.
- Keep changes scoped to the requested task.
- Follow the established architecture and dependencies.
- Never invent test results or claim checks passed without running them.

## Verification
- Run the appropriate tests, lint, and type checks after changes.
- Report checks that could not be run and explain why.
- Review the final diff for unrelated changes and regressions.
